# Adzan Audio Files

Silakan tambahkan file audio adzan Anda di folder ini dengan nama:
- `adzan.mp3` - File utama adzan yang akan diputar

## Format yang Disarankan:
- Format: MP3
- Durasi: 30-60 detik 
- Kualitas: 128kbps atau lebih tinggi
- Volume: Normal (tidak terlalu keras atau pelan)

## Sumber Audio Adzan:
Anda dapat mengunduh file audio adzan dari:
1. https://www.myinstants.com/en/search/?name=adzan
2. https://freesound.org/search/?q=adzan
3. https://www.zapsplat.com/
4. Atau merekam sendiri

Pastikan Anda memiliki izin untuk menggunakan file audio tersebut.
